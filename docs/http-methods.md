# HTTP Methods

## GET
URL: /api/employees
Purpose: Retrieve employees
Status: 200 OK

## POST
URL: /api/employees
Purpose: Create a new employee
Status: 201 Created

## PUT
URL: /api/employees/10
Purpose: Replace employee details
Status: 200 OK

## PATCH
URL: /api/employees/10
Purpose: Update selected employee details
Status: 200 OK

## DELETE
URL: /api/employees/10
Purpose: Delete an employee
Status: 204 No Content
